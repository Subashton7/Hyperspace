☲ HOW THE SHIELD WORKS

Soft seal flips the Windows privacy switch for that sense, so no app can open it. On the mic it also mutes the input device, which silences apps that already had it open.

Hard kill disables the camera in Device Manager, so the light can't come on. Windows asks for admin each time. Toggling the camera back on undoes it.

Hotkeys: Ctrl+Alt+Shift+M mic  ·  Ctrl+Alt+Shift+C camera. These work from any app while HYPERSPACE is running.
